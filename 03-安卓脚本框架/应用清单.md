## 一、游戏加速/VPN工具

### 1. 99手游加速器
- **应用名称**: 99手游加速器 (99 Game Accelerator)
- **包名**: `com.excean.na`
- **开发商**: Excean
- **应用类型**: 游戏加速工具/VPN
- **主要功能**: 游戏网络加速、降低延迟、优化连接
- **描述**: 中国市场流行的手游加速器，通过VPN技术优化游戏网络连接，降低国际服务器延迟，主要服务于玩海外游戏的中国玩家。
- **在项目中的用途**: 降低跨区游戏延迟，优化网络连接质量

### 2. biubiu加速器
- **应用名称**: biubiu加速器 (biubiu Accelerator)
- **包名**: `com.njh.biubiu`
- **开发商**: 广州宁静海网络科技有限公司
- **应用类型**: 游戏加速工具/VPN
- **主要功能**: 手游加速、网络优化、降低游戏延迟
- **描述**: 中国最流行的免费手游加速器之一，专注于优化移动游戏网络连接，支持PUBG、原神等热门游戏的国际服加速，用户基数庞大。
- **在项目中的用途**: 主流游戏加速方案，免费且稳定

### 3. VPN Servers
- **应用名称**: VPN Servers
- **包名**: `pw.dschmidt.vpnapp.app`
- **开发商**: D. Schmidt
- **应用类型**: VPN工具
- **主要功能**: VPN连接、网络代理
- **描述**: 小型VPN应用，提供基础的VPN服务器连接功能。
- **在项目中的用途**: 备用VPN方案
- **注意事项**: 包名使用.pw域名（帕劳顶级域名），需注意安全性和隐私政策

### 4. OpenVPN for Android
- **应用名称**: OpenVPN for Android
- **包名**: `de.blinkt.openvpn`
- **开发商**: Arne Schwabe
- **应用类型**: 开源VPN工具
- **主要功能**: OpenVPN客户端、VPN连接管理
- **描述**: 官方开源的OpenVPN Android客户端，支持标准OpenVPN协议，可导入.ovpn配置文件，是最受信任的VPN客户端之一，广泛用于企业和个人VPN连接。
- **在项目中的用途**: 企业级VPN连接，支持自定义配置
- **优势**: 开源、安全性高、协议标准

### 5. Kitsunebi
- **应用名称**: Kitsunebi (狐火)
- **包名**: `fun.kitsunebi.kitsunebi4android`
- **开发商**: Kitsunebi开发团队
- **应用类型**: 代理/VPN工具
- **主要功能**: V2Ray客户端、Shadowsocks支持、代理工具
- **描述**: 支持V2Ray和Shadowsocks协议的代理客户端，主要用于科学上网，支持多种代理协议和混淆方式。
- **在项目中的用途**: 高级代理方案，支持多种协议
- **优势**: 协议丰富、混淆能力强

### 使用场景
1. **启动阶段**: 脚本自动启动VPN/加速器，建立网络连接
2. **登录阶段**: 通过WEMIX PLAY管理账号和资产
3. **游戏阶段**: 运行NIGHT CROWS或YMIR，执行自动化任务
4. **收益阶段**: 通过WEMIX PLAY管理获得的代币和NFT

### 网络优化策略
- **主方案**: biubiu加速器（免费、稳定、用户多）
- **备用方案**: 99手游加速器
- **企业方案**: OpenVPN（自建服务器）
- **高级方案**: Kitsunebi（多协议支持）

## 五、Proxy模块配置参考

在 `framework/proxy.lua` 中已注册的客户端：

```lua
local PROXY_REGISTRY = {
    ["biubiu"]    = "com.njh.biubiu",
    ["99"]        = "com.excean.na",
    ["kitsunebi"] = "fun.kitsunebi.kitsunebi4android",
    ["openvpn"]   = "de.blinkt.openvpn",
    ["v2ray"]     = "com.v2ray.ang",  -- 注：v2ray未在本清单中
}
```

### 配置示例

```lua
-- config.lua
Config.PROXY_CLIENT = "biubiu"  -- 使用biubiu加速器
Config.PROXY_WAIT = 10          -- 等待10秒建立连接
```

### 扩展新客户端

如需添加新的VPN/加速器客户端：

1. 在本文档中添加应用信息
2. 在 `framework/proxy.lua` 的 `PROXY_REGISTRY` 中注册包名
3. 在 `game/ui_map.lua` 中注册 `start_fn`（点击连接按钮的操作）
4. 更新 `config.lua` 中的 `PROXY_CLIENT` 配置

## 六、注意事项

### 安全性
1. **VPN Servers** (pw.dschmidt.vpnapp.app) 使用非主流域名，需注意隐私政策
2. 所有VPN/代理工具需要在合法合规的前提下使用
3. 避免在VPN连接时传输敏感信息（密码、私钥等）

### 稳定性
1. **biubiu加速器**和**99手游加速器**为主流方案，稳定性较高
2. **OpenVPN**需要自建服务器，成本较高但可控性强
3. **Kitsunebi**协议丰富但配置复杂，适合高级用户

### 兼容性
1. 所有应用均为Android平台
2. 部分应用可能需要特定Android版本支持
3. 区块链游戏（NIGHT CROWS、YMIR）对设备性能要求较高
