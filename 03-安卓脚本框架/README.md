## 当前边界

- 安卓脚本是每游戏独立 fork、独立打包的脚本基座。
- 本目录描述的是框架能力和接入边界，不等于具体脚本包已经完成联调或实机发布。
- 涉及登录恢复、参数同步、热更新下载、SHA-256 校验、`installLrPkg` 安装闭环时，必须以当前源码、测试结果和懒人精灵真机验证为准。

## 当前重点待验证项

- 文件级 SHA-256 校验能力
- `installLrPkg` 返回值语义与失败处理
- 安卓脚本下载、安装、重启、新版本识别闭环
- 401 后统一走 `Verify.ensure_token()` 的恢复策略
- 热更新后与 PCControl 的设备识别连续性
