## 当前边界

- PC 中控是每游戏独立 fork、独立打包的桌面端基座。
- 本目录描述的是框架基座能力与接口边界，不等于某个具体游戏包已经发布。
- 涉及登录可用性、参数同步、热更新安装、exe 自更新和实机联调时，必须以当前源码、测试结果和真实设备验证为准。
- 当前全局设置中的运行守护安装/卸载属于开发期 Python 脚本方案；正式交付期必须改为 EXE 启动器或 Watchdog EXE，详见 [[02-PC中控框架/打包与发布]]。

## 当前重点待验证项

- PCControl 在真实 Verify 环境下的登录成功率
- PC 登录是否占用 Android 授权设备数
- PC 更新包下载、覆盖、重启、回退闭环
- PC 中控 EXE 打包、Watchdog EXE、Windows 计划任务安装/卸载闭环
- 参数编辑 UI 与 `/api/params/get`、`/api/params/set` 的完整联调
