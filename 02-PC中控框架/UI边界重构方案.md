# UI边界重构方案

## 0. 本版纠偏声明

本版相对上一版做了关键纠偏：

1. 删除所有无证据的“未确认账号来源 / 未确认分配来源”等等表述。
2. 当前只确认以下账号来源：
   - 手动录入游戏账号。
   - 客户外部账号数据库。
3. 如果未来需要“平台托管游戏账号库”，必须单独立项、单独设计、单独验证，不能混入当前边界重构方案。
4. 不做远程控制、投屏、scrcpy 类能力。
5. 全局设置不承载游戏参数、游戏账号表、任务路线、物品处理、交易、制造、铸币等内容。
6. 设备设置 / 批量设置才承载游戏运行配置。
7. 账号设置页里的账号是游戏账号，不是 PC 登录账号，不是 Verify 用户账号。
8. 游戏密码必须默认隐藏，但必须支持显示、隐藏、复制、编辑，因为客户可能直接填写真实密码，也可能需要用于其他设置。
9. 设备管理页主操作工具栏建议放到底部，符合批量选择后的实际操作习惯。

## 1. 当前任务目标

### 1.1 目标

建立一份可真实操作、不失真、不幻觉的 PCControl UI / 配置 / 设置边界重构方案，用于指导后续代码拆分、页面重构和文档沉淀。

### 1.2 范围

本方案覆盖：

- 设备管理页面布局。
- 底部主操作工具栏。
- 右侧中控侧栏。
- 全局设置边界。
- 设备设置对话框边界。
- 批量设置对话框边界。
- 游戏账号设置页边界。
- 客户外部账号数据库连接边界。
- 密码显示 / 隐藏 / 复制 / 编辑 / 导出规则。
- 文件级改造建议。
- 迁移顺序与验收清单。

### 1.3 非目标

本方案明确不做：

- 远程控制。
- 投屏。
- scrcpy 接入。
- 公网远控。
- NAT 穿透。
- Relay 远控。
- 把 PCControl 变成远程桌面工具。
- 在全局设置中编辑具体游戏账号。
- 在全局设置中配置游戏任务路线、物品处理、制造、铸币等游戏运行参数。
- 声称当前存在平台托管游戏账号库。
- 声称当前存在可用的未确认云端账号来源。

## 2. 证据来源与可信度

### 2.1 已确认源码证据：当前 PCControl

从 GitHub 当前 HiveGreatSage-PCControl 源码可确认：

1. `ui/widgets/settings_dialog.py` 当前名称是“全局设置弹窗”，但标签页包含：账号设置、脚本参数、仓库设置、物品设置、制造设置、活动设置、铸币设置、其他设置。
2. 该弹窗当前把“账号设置”用于 API 地址、项目 UUID、同步间隔等本地配置。
3. 该弹窗当前把“脚本参数”放在全局设置里，并通过 Verify 参数接口加载和保存。
4. 该弹窗当前把仓库、物品、制造、活动、铸币标注为游戏层 Phase 2 占位。
5. `config/default.yaml` 当前已有 server、debug、network、sync、ui、adb、team、update、log 等配置段。
6. `ui/main_window.py` 当前设备页工具栏在表格上方，包含批量设置、批量启动、批量停止、批量激活、导出、解绑等按钮。
7. `ui/widgets/batch_dialog.py` 当前批量弹窗尺寸较小，分为基础设置、任务控制、激活操作。

### 2.2 已确认源码证据：Ymir_CC.zip

从用户上传的 `Ymir_CC.zip` 本地解压精读可确认：

1. `ui/tabs/device_info/device_tab.py` 文件头明确说明其布局是“左侧设备表 + 右侧四组 + 底部四按钮”。
2. 右侧四组包括：数据统计、分组信息、列表操作、其他操作。
3. 底部按钮包括：全选、反选、导出 CSV、刷新。
4. 设备页有列显隐、手动分组、区服分组、自动刷新间隔、偏好持久化等设计。
5. `ui/dialogs/settings/dialog.py` 是设备设置对话框，不是平台全局设置；它按设备、多设备、未传设备分别保存 profile。
6. 该设置对话框使用大尺寸 QDialog + QTabWidget + 底部状态栏 + 左侧重置按钮 + 右侧保存按钮的风格。
7. `ui/dialogs/settings/pages/account_page.py` 的账号设置页包含游戏账号、密码、验证邮箱、大区、小区、主角色、职业等字段。
8. 账号设置页中的密码默认掩码显示，真实密码存于 `Qt.UserRole + 100`，右键菜单支持显示、隐藏、复制；编辑后重新掩码。

- HiveGreatSage-PCControl 是否已有账号密码安全存储方案。

## 3. 核心边界总纲

### 3.1 一句话边界

PCControl 的设置体系必须拆成三类：

```text
全局设置       = 平台附加能力 / 客户环境 / 本地运行环境
设备设置       = 单设备游戏运行配置
批量设置       = 多设备批量应用配置
```

### 3.2 账号相关边界

```text
游戏账号设置     = 设备设置 / 批量设置的一部分
客户数据库连接   = 全局设置的一部分
具体游戏账号编辑 = 不属于全局设置
```

### 3.3 禁止混用的词

当前方案中禁止使用以下无证据或容易误导的词：

```text
未确认账号来源
未确认的托管账号库表述
未确认的平台账号库表述
未确认的账号分配表述
未确认的云端账号库表述
```

如果未来需要类似能力，应命名为：

```text
待设计：平台托管游戏账号库
状态：未确认 / 未实现 / 不作为当前方案依据
```

## 4. 设备管理页布局重构

### 4.1 当前问题

当前 PCControl 设备页的批量操作工具栏在表格上方。对于中控类桌面软件，用户通常先看表格、筛选、勾选设备，然后执行操作；按钮放在底部更贴近鼠标操作路径。

### 4.2 建议目标布局

```text
┌────────────────────────────────────────────────────────────┐
│ TopBar：用户 / 授权 / 到期 / API连接 / 同步状态              │
├────────────────────────────────────────────────────────────┤
│ TabBar：设备管理 / 组队管理 / 订单 / 价格 / 日志             │
├────────────────────────────────────────────────────────────┤
│ 筛选栏：搜索 / 状态 / 角色 / 区服 / 分组 / 心跳状态          │
├──────────────────────────────────────┬─────────────────────┤
│                                      │ 右侧中控侧栏          │
│ 设备超级表格                          │ - 数据统计            │
│                                      │ - 分组信息            │
│                                      │ - 列显示/隐藏          │
│                                      │ - 自动刷新            │
│                                      │ - 当前选中摘要          │
├──────────────────────────────────────┴─────────────────────┤
│ 底部主操作工具栏                                             │
│ 全选 / 反选 / 清空 / 批量设置 / 启动 / 停止 / 重启 / 激活 / 导出 │
├────────────────────────────────────────────────────────────┤
│ 状态栏：最近操作 / 同步错误 / 批量任务进度                    │
└────────────────────────────────────────────────────────────┘
```

### 4.3 底部工具栏分区

#### 左侧：选择类操作

```text
全选
反选
清空选择
仅选在线
仅选异常
```

#### 中间：高频批量操作

```text
批量设置
启动脚本
停止脚本
重启脚本
激活设备
解绑设备
```

#### 右侧：辅助操作

```text
刷新
导出CSV
导出诊断
打开日志
```

### 4.4 硬性规则

```text
规则 1：设备管理页主操作工具栏默认放在底部。
规则 2：顶部只保留状态、导航、筛选，不放大批量操作区。
规则 3：底部工具栏必须实时显示已选设备数。
规则 4：底部工具栏不得加入远程控制、投屏、接管等按钮。
规则 5：右键菜单也不得加入远程控制、投屏、接管等能力。
```

## 7. 客户外部账号数据库边界

### 7.1 已确认需求

部分客户可能有自己的游戏账号数据库，PCControl 需要允许在全局设置中连接客户自己的数据库。

### 7.2 正确位置

```text
全局设置 / 客户外部账号数据库
```

这里只配置连接、字段映射、拉取策略、连接测试。

### 7.3 错误做法

```text
错误：把客户所有游戏账号复制到全局设置里编辑。
错误：把游戏账号表做成全局设置页。
错误：把客户数据库中的密码直接写进 default.yaml。
错误：把客户数据库连接密码打印进日志。
```

### 7.4 字段映射建议

```text
客户数据库字段映射
├── account           -> 游戏账号
├── password          -> 游戏密码
├── email             -> 验证邮箱
├── email_password    -> 邮箱密码
├── region_big        -> 大区
├── region_small      -> 小区
├── role_index        -> 主角色
├── profession        -> 职业
├── status            -> 账号状态
└── remark            -> 备注
```

### 7.5 拉取策略

```text
手动拉取
启动时拉取
定时拉取
只拉取账号摘要
按需拉取真实密码
```

### 7.6 与设备设置的关系

```text
全局设置：配置客户数据库连接。
设备设置：选择账号来源为客户外部数据库，并选择/绑定具体账号。
批量设置：从客户外部数据库批量分配账号。
```

## 8. 设备设置对话框

### 8.1 定义

设备设置对话框处理的是：

```text
一个设备的游戏运行配置
```

不是 PC 客户端全局配置。

### 8.2 建议视觉风格

借鉴 Ymir_CC 设置对话框：

```text
大尺寸窗口：建议 1400×800 或 1400×850
顶部标题栏
中间 QTabWidget 多页签
底部状态栏
左侧：重置当前页面 / 全部重置
中间：状态文本
右侧：保存当前页面 / 全部保存 / 关闭
```

### 8.3 建议页签

```text
设备设置对话框
├── 主要设置
│   ├── 运行模式
│   ├── 主线任务
│   ├── 副本设置
│   └── 消耗品设置
│
├── 账号设置
│   ├── 游戏账号
│   ├── 游戏密码
│   ├── 验证邮箱
│   ├── 邮箱密码
│   ├── 大区
│   ├── 小区
│   ├── 主角色
│   └── 职业
│
├── 物品处理
├── 购买设置
├── 交易设置
├── 制造设置
├── 铸币设置
└── 其他游戏参数
```

### 8.4 保存真相源

```text
本地 profile = 草稿 / 最近编辑缓存 / 离线临时保存
Verify / 后端配置接口 = 最终配置真相源（待接口确认）
AndroidScript = 运行时消费端
```

注意：

- 不能照搬 Ymir_CC 的本地 JSON 作为最终真相源。
- 本地 profile 必须明确标记为草稿或缓存。
- 保存成功后需要有同步状态，如 `synced=true`、`synced_at`、`remote_version`。

## 9. 账号设置页

### 9.1 已确认边界

```text
账号设置页里的账号 = 游戏账号
账号设置页属于设备设置 / 批量设置
账号设置页不属于全局设置
```

### 9.2 当前允许的账号来源

```text
手动输入
客户外部账号数据库
```

禁止写：

```text
从未确认账号来源分配
从未确认的平台账号库表述分配
```

### 9.3 建议字段

```text
账号设置页
├── 序号
├── 启用
├── 账号来源
│   ├── 手动输入
│   └── 客户外部账号数据库
├── 账号类型
├── 游戏账号
├── 游戏密码
├── 验证邮箱
├── 邮箱密码
├── 大区
├── 小区
├── 主角色
├── 职业
├── 上次登录时间
├── 上次邮件验证时间
├── 账号状态
└── 备注
```

### 9.4 密码显示 / 隐藏规则

```text
默认状态：密码列显示 ******
单行操作：右键密码单元格 -> 显示密码
单行操作：右键密码单元格 -> 隐藏密码
单行操作：右键密码单元格 -> 复制密码
全局操作：顶部按钮 -> 显示全部密码
全局操作：顶部按钮 -> 隐藏全部密码
编辑规则：双击密码单元格可编辑真实密码
编辑完成：自动恢复为 ****** 显示
内部值：保存真实密码
```

### 9.5 密码安全边界

## 10. 批量设置对话框

### 10.1 当前问题

当前批量弹窗偏早期骨架，尺寸较小，功能集中在角色、区服、脚本操作、激活操作。

### 10.2 新批量设置目标

批量设置处理的是：

```text
多设备参数批量应用
多设备账号批量分配
多设备任务操作
多设备差异预览
多设备应用结果
```

### 10.3 建议结构

```text
批量设置对话框
├── 目标设备摘要
│   ├── 已选设备数
│   ├── 在线设备数
│   ├── 异常设备数
│   └── 不可应用设备数
│
├── 批量账号
│   ├── 保持不变
│   ├── 手动批量导入
│   └── 从客户外部数据库分配
│
├── 批量任务
│   ├── 启动任务
│   ├── 停止任务
│   ├── 重启任务
│   └── 切换任务配置
│
├── 批量参数
│   ├── 只修改勾选字段
│   ├── 未勾选字段保持原值
│   └── 显示差异预览
│
├── 差异预览
│   ├── 设备
│   ├── 参数
│   ├── 原值
│   ├── 新值
│   └── 风险提示
│
└── 应用结果
    ├── 成功
    ├── 失败
    ├── 跳过

```

### 10.4 批量设置硬规则

```text
批量设置不能默认覆盖所有字段。
必须有字段级勾选。
未勾选字段保持原值。
敏感字段如密码，必须明确勾选才可批量覆盖。
批量覆盖密码必须二次确认。
每台设备必须有成功 / 失败 / 跳过结果。
```

## 14. 风险清单

### 风险 1：继续把全局设置当成万能设置

后果：游戏参数、客户环境、运行环境混在一起，长期不可维护。

规避：全局设置只允许平台附加能力和客户环境配置。

### 风险 2：重新制造无证据账号来源

后果：文档和代码设计会基于不存在的模块展开。

规避：当前只允许手动输入和客户外部账号数据库。

### 风险 3：本地 profile 变成事实源

后果：Verify、AndroidScript、PCControl 三端配置不一致。

规避：本地 profile 只作为草稿或缓存。

### 风险 4：密码处理过度安全化或过度放开

后果：

- 过度安全化：客户无法核对、复制、使用真实密码。
- 过度放开：日志、导出、诊断泄露真实密码。

规避：默认隐藏，允许主动显示；日志永不打印；导出默认脱敏；明文导出二次确认。

### 风险 5：设备分组和游戏组队混淆

后果：UI 管理能力和游戏协同能力互相污染。

规避：`core/device_group` 与 `core/team` 分离。

## 17. 最终结论

本次边界重构的核心不是“换一套好看的界面”，而是把 PCControl 的长期边界重新扶正：

```text
全局设置只管平台附加能力。
设备设置只管单设备游戏运行配置。
批量设置只管多设备批量应用。
账号设置页里的账号是游戏账号。
客户外部数据库只在全局设置中配置连接和字段映射。
具体游戏账号和密码编辑在设备设置 / 批量设置中完成。
设备管理页主操作工具栏放底部。
密码默认隐藏，但必须允许显示、隐藏、复制、编辑和受控明文导出。
当前方案不承认任何未证实的账号来源。
```
