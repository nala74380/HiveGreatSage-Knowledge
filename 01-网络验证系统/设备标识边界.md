# 设备标识边界

> 最后更新: 2026-05-18（设备标识重构同步）

## 当前结论

当前主线设备标识体系如下：

| 字段 | 含义 |
|------|------|
| `device_id` | 设备编号，用于登录绑定、心跳归属、运行时数据关联 |
| `device_id` | 用户填写设备编号，用于业务展示和人工识别 |
| `connection_type` | 连接类型：usb / tcp / unknown |
| `connection_label` | 连接标识展示串：USB 显示 `SN:xxxx`，TCP 显示 `IP:端口` |

## 当前源码状态

- `DeviceBinding` 已新增 `device_id` / `connection_type` / `connection_label`
- `DeviceRuntime` 已新增 `device_id` / `connection_type` / `connection_label`
- `/api/device/imsi` 已删除
- AndroidScript 已删除 IMSI 回退逻辑
- PCControl 与 AndroidScript 正在对齐新设备标识体系

## 设计要求

```text
1. device_id 必须稳定，不能由用户手工修改。
2. device_id 可以由用户手工填写或调整，但不能影响绑定唯一性。
3. USB 设备连接标识展示为 SN。
4. TCP 设备连接标识展示为 IP:端口。
5. 后台、日志、前端页面当前直接展示设备原文字段。
```
